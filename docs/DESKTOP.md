# オフラインGNSSデスクトップアプリ

## 起動

Windows / macOS共通。Tkinterを含むPython 3.12を使用します。

```sh
uv sync
uv run python -m gnss_maps.desktop
```

保存済みNMEAログを指定して起動する場合：

```sh
uv run python -m gnss_maps.desktop --log data/example.log
```

初回の依存関係インストールにはネット接続が必要です。準備後のアプリはPCのインターネット接続を使用しません。
`No module named _tkinter`が出た場合は、Tkinterを含むPythonを用意してそのPythonで`uv sync --python <Pythonのパス>`を実行してください。

## 計測

1. 接続タブでUSBシリアルポートと機器の通信速度を選び、接続します。
2. 受信・測位状態を確認します。機器なしでは「デモ（架空データ）」で試せます。
3. 記録開始を押し、計測名を入力します。
4. 記録停止で生ログを確定します。受信は継続します。

保存先は初期状態で`data/desktop/logs/`です。`--data-dir`で変更できます。
解析できないデータも受信したバイト列のまま保存します。表示用の日時は生ログへ追加しません。
受信だけの状態ではディスクへ保存しません。

USB切断時は取得済みのログを保持します。接続タブから機器を選び直して再接続してください。
誤った機器への接続を避けるため、現時点では自動再接続は行いません。
記録中の切断は記録ファイルを開いたまま待機し、復帰後は別区間として続けます。
明示的な切断・終了は記録停止を確認します。
保存失敗時は記録状態をエラー表示に変更します。受信表示が続いても保存できているとは限りません。

## 地図

地図タブから地形図・航空写真それぞれの**画像MBTiles**を登録します。
PNG/JPEGなどのラスター画像に対応し、ベクトルタイルと3D地形には対応しません。
標準のTMS行番号、およびmetadataで`scheme=xyz`を指定したデータに対応します。
画像データは複製せず登録先を参照するので、ファイルを移動しないでください。

地図ファイルには`metadata(name,value)`と`tiles(zoom_level,tile_column,tile_row,tile_data)`が必要です。
`metadata`の`bounds`（西,南,東,北）と`attribution`（出典）の設定を推奨します。
外部サーバーへのフォールバックはありません。地図未取得・範囲外でも受信と記録を続けられます。
地図データは同梱していません。商用利用・保存・再配布条件を満たすデータを別途用意してください。
ライブラリのライセンスは地図データの使用許諾を兼ねません。

## 履歴と生データ

履歴一覧をダブルクリックするか、生ログを開くから`.log`・`.txt`・`.nmea`を選びます。
シークバーは記録内の経過時間を表します。再生速度、前後の測位点への移動、全経路表示を切り替えられます。
RMCと対応した測位点は日付付きJST、対応しない点は日付不明と表示します。
時刻逆行は受信順を保った別区間として扱い、日付を勝手に補いません。
読み込みは別スレッドで行い、中止できます。入力は150 MB以下に制限しています。

詳細タブでは直近1,000行の生データを確認できます。履歴ではファイル末尾の1,000行です。
履歴で表示する「読込」時刻はファイルを読み込んだPC時刻であり、元の受信時刻ではありません。
表示一時停止は受信・記録に影響しません。マーカーをクリックすると選択点のGGAと対応するRMCを表示します。
CSV/KML出力と生ログの別名保存ができます。履歴を表示中もライブ受信・記録は継続します。

## 表示と保存の違い

ライブ画面は最大約50,000点を保持し、超過時は古い10,000点を表示用メモリから外します。
生ログは間引かず保存します。ライブ記録のCSV/KML出力は生ログを再解析します。
描画は区間ごとに点を間引いて負荷を抑えます。保存座標は丸めません。
未測位、2秒超の間隔、時刻逆行、設定値を超える位置変化で経路を分割します。
受信間隔と位置飛びのしきい値は接続タブから変更できます（ライブ解析に適用）。
FIXは測位品質であり、実測した位置誤差を保証する表示ではありません。

## ファイル構造

| ファイル | 役割 |
|---|---|
| `gnss_maps/desktop.py` | Tk画面、地図操作、生データ閲覧、履歴シーク・再生・出力 |
| `gnss_maps/session.py` | シリアル受信、原文記録、時刻解析、区間分割、ログ読み込み |
| `gnss_maps/offline_map.py` | ネット接続しない地図表示、画像MBTilesの読込 |
| `gnss_maps/nmea.py` | チェックサム検証と緯度経度変換 |
| `gnss_maps/timed.py` | UTC/JSTと従来の時刻別出力 |
| `gnss_maps/live.py` | 既存のブラウザ版と共通のNMEA補助関数 |
| `tests/test_desktop.py` | 切断・保存失敗・時刻・不正データの検証 |
| `scripts/check_desktop.py` | 実際のTk画面でデモ受信・記録・履歴再生を検証 |

## 検証と残る制限

```sh
uv run python -m unittest discover -s tests -v
uv run python scripts/check_desktop.py
```

macOSで自動テストとTkイベントループによる起動・記録・読み込み・シーク・再生を確認しています。
地形図・航空写真の表示は、ネット通信を禁止した検証スクリプトで確認しています。
Windows実機とGNSS実機による切断復旧は未検証です。
UI自動操作ツールが応答待ちになったため、目視によるレイアウト検査は未完了です。
自動再接続、履歴名変更・削除、任意日時の直接入力、全測位点を個別マーカーにする機能は未実装です。

## 標準プリセットと手元の地図

標準の配信元として国土地理院の地形図（標準地図）・航空写真を設定しています。
地図タブの「表示中心の周辺を準備」から、約1 km四方、倍率14〜18を取得できます。
準備時だけネット接続を使用し、画像を要求する範囲が国土地理院に伝わります。生ログ全体は送信しません。
取得済み地図は`data/desktop/presets/`に保存し、次回起動でも利用します。
全国の詳細地図を同梱する機能ではありません。未取得の場所では事前準備が必要です。
未提供の画像（HTTP 404）は欠落として数えます。通信失敗・中止時は従来の完成済みファイルを保持します。
手元の画像MBTilesは任意で追加でき、「標準プリセットに戻す」で保存済みの標準地図に戻せます。
地図を商用アプリに同梱・再配布する場合の条件は別途確認してください。
