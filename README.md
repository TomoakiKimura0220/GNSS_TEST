# GNSS_TEST — GNSS観測ノート

ZED-F9Pなどの受信機が出力するNMEAデータをUSBで読み取り、位置と移動履歴を表示するPythonプロジェクトです。生データの保存、履歴の再生、CSV・KML出力に対応しています。

macOS／Windows向けです。ブラウザー版では、保存済みの地形図・航空写真を使い、PCがオフラインでも地図を表示できます。Google MapsのAPIキーは不要です。

初めて使う場合は「導入と起動」から「計測と生データの保存」まで進めてください。履歴、地図、ファイル構造は必要なときに参照できます。

## 機器とデータの流れ

```text
GNSS衛星 → アンテナ → ZED-F9P（測位計算）
                          ↑ 補正データ
基準局 → インターネット → モバイルルーター → ESP32

ZED-F9Pの測位結果 → USBシリアル → PCのPythonアプリ
                                  ├─ 生データを.logに保存
                                  ├─ 座標と履歴をSQLiteに保存
                                  └─ ブラウザーに地図・グラフを表示
```

ESP32側の補正データ受信は、貸与された機器の設定を利用する想定です。このアプリからNTRIP接続や受信機の設定変更は行いません。PCの地図表示と、ESP32が使うモバイル通信は別です。

## 導入と起動

### 初回の準備

1. [このリポジトリ](https://github.com/TomoakiKimura0220/GNSS_TEST)の「Code → Download ZIP」で取得して展開します。Gitを使う場合は下記のコマンドでも取得できます。
2. [uvの公式手順](https://docs.astral.sh/uv/getting-started/installation/)に従ってuvを導入します。
3. `pyproject.toml` があるフォルダーでターミナルを開きます。Windowsではエクスプローラーのアドレス欄に `powershell` と入力します。
4. 依存関係を用意して起動します。初回のダウンロードにはネット接続が必要です。

```sh
# Gitで取得する場合のみ
git clone https://github.com/TomoakiKimura0220/GNSS_TEST.git
cd GNSS_TEST

# ZIPの場合も、展開したフォルダーでここから実行
uv sync --locked
uv run python -m gnss_maps.live
```

ブラウザーが開かなければ、同じPCで http://127.0.0.1:8765/ を開きます。プロジェクトではPython 3.12を指定しています。

### 機器なしで試す

1. 接続先で「デモ（架空の位置）」を選びます。
2. 「計測開始」を押します。
3. 地図・散布図・時系列・生データのタブを切り替えます。
4. 「停止して保存」を押し、履歴のスライダーを動かします。

デモの位置は架空です。保存した地図の範囲外では背景が表示されません。

## 計測と生データの保存

1. 受信機をデータ通信対応USBケーブルでPCにつなぎます。
2. Tera Termなど、同じシリアルポートを使うソフトを閉じます。
3. 「ポート一覧を更新」を押し、Windowsなら `COM3`、Macなら `/dev/cu.usbmodem...` など、実際に表示された接続先を選びます。
4. 通信速度を機器の設定に合わせます。画面の初期値は38400です。
5. 計測名を入力し、「計測開始」を押します。
6. 終わったら「停止して保存」を押します。

**「計測開始」と同時に、生データの自動保存も始まります。**
受信したバイト列を `.log` に保存するため、表示フィルターで隠した行や解析できない行も記録に残ります。タブの切り替えや生データの「表示を一時停止」は記録に影響しません。

保存した履歴を選び、「元ログ保存」でログを取り出せます。「CSV保存」「KML保存」では解析済みの座標を書き出します。

```text
data/live/
├── history.sqlite3     # 計測一覧・座標・日時・測位品質
└── <計測ID>.log        # シリアル通信で受け取った生データ
```

ここでいう生データは受信機から出力されたNMEAなどです。衛星の観測値や搬送波データが出力されていなければ、それらを記録することはできません。

終了するときは計測を停止し、ターミナルで `Ctrl+C` を押します。ブラウザーを閉じただけではPythonの受信・記録は終了しません。バックアップするときはPythonを終了してから `data/live/` 全体をコピーしてください。

## 4つの表示タブ

| タブ | 表示・操作 |
| --- | --- |
| 地図 | 品質別の軌跡、地形図／航空写真の切り替え、拡大縮小、最新位置の追従 |
| 散布図 | 最初の有効位置を原点とした東西・南北の変位。単位は概算m |
| 時系列 | 測位品質・使用衛星数・HDOP。グラフのクリックで時点を選択 |
| 生データ | 元ログの行番号とNMEA原文。GGA／RMCなどの絞り込み、表示の一時停止 |

選択した履歴と表示時点はタブ間で共有します。散布図は最初の位置からの変位であり、真値に対する誤差ではありません。

| GGAの品質 | 意味 | 色 |
| --- | --- | --- |
| 0 | 測位不可。位置として採用しない | — |
| 1 | 単独測位 | 灰 |
| 2 | 差分補正 | 橙 |
| 4 | RTK FIX（整数解） | 緑 |
| 5 | RTK FLOAT（実数解） | 紫 |

FIXになったことと、実際の位置誤差を確認したことは別です。精度評価には既知の基準位置などとの比較が必要です。

## 履歴を確認する

### このアプリで保存した計測

1. 「保存した履歴」から計測を選びます。
2. スライダーで表示時点を選びます。その点までの経路、座標、品質、日時を表示します。
3. 「履歴を再生」で点を順に表示します。「全軌跡・最後の点」で末尾へ戻ります。

ブラウザー版の再生は1点ごとに0.2秒で進みます。計測中の待ち時間を再現する実時間再生ではありません。

### Tera Termなどで保存したログ

ログを `data/measurement.log` に置き、次のように起動します。

```sh
uv run python -m gnss_maps.live --replay "data/measurement.log"
```

接続先で「指定したログを再生」を選び、「計測開始」を押します。GGAごとに0.2秒待ちながら読み込むため、長いログでは読み込みに時間がかかります。入力ログは変更せず、再生した内容を別の計測として保存します。

ファイルを直接開いて履歴を確認する場合は、[デスクトップ版](docs/DESKTOP.md)も利用できます。

```sh
uv run python -m gnss_maps.desktop --log "data/measurement.log"
```

デスクトップ版はTkinterの画面で、ブラウザー版とは保存先・操作が異なります。

## オフライン地図を準備する

地図画像はGitHubに同梱していません。対象範囲の画像を事前に保存します。

1. ネット接続がある場所で `uv run python -m gnss_maps.desktop` を起動します。
2. 対象地域のログを開くなどして地図の表示中心を合わせます。
3. 地図タブの「表示中心の周辺を準備」で地形図・航空写真を取得します。
4. 取得が完了したら、ブラウザー版を起動するかページを再読み込みします。

既定では国土地理院の画像を約1 km四方、ズーム14〜18で取得します。取得時は対象範囲を含むタイルの要求を国土地理院へ送ります。

```text
data/desktop/presets/
├── std.mbtiles             # 地形図
└── seamlessphoto.mbtiles   # 航空写真
```

ブラウザー版はこの2ファイルを参照します。保存範囲外は背景が空欄になりますが、受信と記録は続けられます。高倍率では保存画像を拡大するため、画像自体の詳細は増えません。地形図は2D画像で、3D地形表示ではありません。

手元の画像MBTilesを画面から登録する操作はデスクトップ版にあります。ブラウザー版には任意ファイルの登録画面はまだありません。[地図の形式・取得手順](docs/DESKTOP.md#地図)も参照してください。

## KML・CSVに変換してGoogleマイマップで使う

```sh
uv run python -m gnss_maps "data/measurement.log" --out result --time-step 10
```

| 出力 | 内容 |
| --- | --- |
| `result/track.kml` | 経路と開始・終了地点 |
| `result/time_points.kml` | 日時付き地点。既定は10秒間隔 |
| `result/points.csv` | 全有効点の座標、UTC時刻、品質、区間 |
| `result/time_points.csv` | 日時付き地点の一覧 |
| `result/summary.json` | 点数や区間数などの集計 |

Googleマイマップで `track.kml` をインポートします。日時付きピンは `time_points.kml` を別レイヤーに読み込みます。詳しい操作と変換の仕組みは[ログ変換ガイド](docs/CONVERSION.md)にまとめています。

## ファイル構造と役割

```text
GNSS_TEST/
├── README.md                  # 導入と基本操作
├── pyproject.toml             # Pythonの依存関係とプロジェクト設定
├── uv.lock                    # 依存関係のバージョンを固定
├── .python-version            # 使用するPython（3.12）
├── .gitignore                 # 実測データなどをGitから除外
├── gnss_maps/
│   ├── __main__.py            # 保存ログからKML・CSVを作る入口
│   ├── nmea.py                # GGAの検査、DMM→DD変換
│   ├── timed.py               # RMCの日付、UTC/JST、日時付き地点の出力
│   ├── live.py                # ブラウザー版のUSB受信、保存、HTTP API
│   ├── web/
│   │   ├── index.html         # 画面の構造
│   │   ├── app.js             # タブ、地図、グラフ、履歴操作
│   │   ├── style.css          # 配色、配置、フォント
│   │   ├── fonts/             # IBM Plexフォントとライセンス
│   │   └── vendor/leaflet/    # 地図描画ライブラリとライセンス
│   ├── desktop.py            # Tkinter版の画面
│   ├── session.py            # Tkinter版の受信、記録、履歴解析
│   ├── offline_map.py        # MBTilesの検査とTkinter版の地図表示
│   └── presets.py            # 国土地理院画像の事前取得
├── docs/
│   ├── LIVE.md               # ブラウザー版の詳しい操作・制限
│   ├── DESKTOP.md            # デスクトップ版の操作・地図の準備
│   └── CONVERSION.md         # KML変換、NMEAの形式、座標変換
├── tests/                    # 解析、受信、切断、保存、HTTPのテスト
├── scripts/                  # Tk画面と地図描画の検証スクリプト
├── data/                     # 入力ログ、履歴、地図（.gitkeep以外はGit対象外）
├── result/                   # 変換結果（Git対象外）
└── .venv/                    # uvが用意する実行環境（Git対象外）
```

ブラウザー版のコードは `live.py → web/index.html → web/app.js` の順に読むと、受信から表示までを追えます。座標変換を知りたい場合は `nmea.py`、日時の処理は `timed.py` を参照してください。

## 困ったとき

| 症状 | 確認・対処 |
| --- | --- |
| `uv` が認識されない | uvを導入後、ターミナルを開き直す |
| `gnss_maps` が見つからない | `pyproject.toml` のあるフォルダーで実行する |
| USBポートが出ない | データ通信対応ケーブルを確認し、抜き差しして一覧を更新する |
| ポートを開けない | Tera Termなど同じポートを使うソフトを閉じる |
| 受信中だが位置が出ない | 生データでGGAの品質と座標欄を確認する |
| 地図が白い／背景がない | 地図を取得済みか、表示位置が保存範囲内かを確認する |
| USBが途中で切れた | エラーを確認し、機器をつなぎ直して新しい計測を開始する |
| 保存エラーが出る | 保存先の空き容量と書き込み権限を確認する |
| ポート8765が使用中 | `uv run python -m gnss_maps.live --port 8766` で起動する |
| Tkinter版で `_tkinter` がない | [デスクトップ版の導入手順](docs/DESKTOP.md#起動)を参照する |

解決しない場合は[Issues](https://github.com/TomoakiKimura0220/GNSS_TEST/issues)にOS、操作、エラー内容を記載してください。実測ログには位置情報が含まれるため、公開する内容を確認してください。

## 検証範囲と制限

```sh
uv run python -m unittest discover -s tests -v
```

- macOS・Python 3.12で自動テスト21件が通っています。ブラウザーのタブ切り替え、デモ受信・保存、履歴シーク、地形図・航空写真の表示を確認しています。
- Windows実機と、このアプリによるGNSS実機のUSB受信は未検証です。
- ブラウザー画面は直近50,000点まで、生データは最大1,000行を表示します。元ログと全座標は保存します。
- 生データの履歴表示は選択UTCの最初の一致を使うため、複数日に同じUTCが出るログには制限があります。
- 時系列は有効な測位点が対象です。測位不可の品質0は生データで確認します。
- 初回セットアップ・地図の取得・外部Googleマップリンクの利用にはネット接続が必要です。

## 用語とライセンス

| 用語 | このアプリでの意味 |
| --- | --- |
| NMEA | 受信機が出力する、GGAやRMCなどの文字列データ |
| GGA | UTC時刻・緯度経度・測位品質などを含む文 |
| RMC | 日付・UTC時刻・緯度経度などを含む文 |
| DMM／DD | 度と分の座標表記／小数の度の表記 |
| HDOP | 衛星配置による水平方向の精度低下の指標。誤差のm値ではない |
| MBTiles | 地図タイルをSQLiteファイルにまとめた形式 |

同梱しているLeafletの条件は[LICENSE](gnss_maps/web/vendor/leaflet/LICENSE)、IBM Plexの条件は[Sans JP](gnss_maps/web/fonts/ibmplexsansjp-OFL.txt)・[Mono](gnss_maps/web/fonts/ibmplexmono-OFL.txt)を参照してください。

地図の使用条件はライブラリとは別です。[地理院タイル一覧](https://maps.gsi.go.jp/development/ichiran.html)と[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)を確認してください。計測ログ、地図画像、生成したKML・CSVはこのリポジトリには含めていません。
