# リアルタイム受信と履歴表示

USBでNMEAを受信し、ブラウザーで現在位置と軌跡を確認します。
計測ごとに元ログと座標を保存し、停止後や再起動後にも履歴を選べます。
WindowsとmacOS共通のPythonコードです。

## 起動

リポジトリを更新し、`pyproject.toml` のあるフォルダーで実行します。
Gitで取得した場合の更新方法は `git pull --ff-only` です。
ZIPの場合は最新版を別フォルダーに展開し、必要なら以前の `data/live/` を移します。

```sh
uv sync --locked
uv run python -m gnss_maps.live
```

ブラウザーが自動で開きます。
開かない場合は、同じPCで <http://127.0.0.1:8765> にアクセスします。
終了するには、画面で計測を停止してからターミナルで Ctrl+C を押します。
ブラウザーのタブを閉じても、Pythonが動いていれば記録は続きます。

## 画面からログを一括インポートする

1. 「ログを読み込む」で `.log`・`.txt`・`.nmea` ファイルを選びます。
2. 「一括インポート」を押します。
3. 完了すると履歴が選択され、地図・各タブ・シークバーで確認できます。

NMEAテキストを50 MiBまで読み込めます。元ファイルは変更せず、元データのコピーと解析済み座標を保存します。実測時刻の間隔を待たずに一括処理します。読み込み中もUSBの受信・記録は継続します。
有効なGGA位置がないファイルはエラーになり、履歴へ登録しません。
ファイルは同じPCのPythonサーバーへ送られ、外部サービスへは送信しません。
日時はログ内のRMCとGGAから取得します。履歴の登録時刻はインポートしたPC時刻です。

## 機器なしで試す

接続先の「デモ（架空の位置）」を選び、「計測開始」を押します。
架空の軌跡と、品質5、4、0の変化を表示します。
デモは約5分で終了します。
履歴には「デモ」と明記し、実測と区別します。

保存済みのNMEAログも、受信するように再生できます。

```sh
uv run python -m gnss_maps.live --replay "data/measurement.txt"
```

画面の接続先で「指定したログを再生」を選びます。
GGAごとに0.2秒待つ方式なので、元ログの空白時間を再現する再生ではありません。
履歴には「ログ再生」と表示します。

## USBから計測する

1. 受信機をデータ通信対応USBケーブルでつなぎます。
2. Tera Termやu-centerなど、同じポートを開いているソフトを切断します。
3. 「ポート一覧を更新」を押します。
4. Windowsなら `COM3` など、Macなら `/dev/cu.usbmodem...` や `/dev/cu.usbserial...` を選びます。番号や名前は実機で異なります。
5. 通信速度を選び、計測名を入力して「計測開始」を押します。
6. 終了したら「停止して保存」を押します。

通信条件は8ビット、パリティなし、ストップ1、フロー制御なしです。
通信速度の初期値は38400ですが、USB-UART経由の場合は機器の設定と合わせます。
GNSS USB直結の場合には、この速度指定が実際のデータ転送速度を決めないことがあります。
機器やOSによってはUSBドライバーが必要です。
プログラムは測位設定やWi-Fi設定を変更せず、受信データを読み取ります。
シリアルポートを開くと制御線の状態が変わり、基板によっては再起動する可能性があります。

補正データの取得は、既存のESP32側の動作を想定しています。
このPythonプログラムにはNTRIPクライアント機能はありません。

## オフライン地図と表示タブ

地図描画には同梱したLeaflet 1.9.4を使用します。APIキーは不要です。
地図、JavaScript、CSS、IBM Plexフォントはローカルから読み込みます。

保存済みの地図は次の場所から読み込みます（起動したフォルダーが基準です）。

- `data/desktop/presets/std.mbtiles`：地形図
- `data/desktop/presets/seamlessphoto.mbtiles`：航空写真

地図の事前取得については [デスクトップ版の手順](DESKTOP.md) を参照してください。
保存範囲外や未取得の場所は背景が表示されません。経路は表示できます。
保存済み画像より高倍率に拡大しても、画像自体の詳細は増えません。
画面内の「この点をGoogleマップで開く」はオンラインの外部リンクです。

| タブ | 内容 |
| --- | --- |
| 地図 | 地形図・航空写真に品質別の軌跡を表示。拡大縮小・移動が可能 |
| 散布図 | 最初の有効点を原点とした東西・南北の変位（概算m）。真値に対する誤差ではない |
| 時系列 | 品質・衛星数・HDOPを経過時間で表示。グラフをクリックして時点を選択 |
| 生データ | 元ログを行番号付きで表示。GGA/RMC/チェックサム不正などを絞り込み可能 |

タブを切り替えても受信・保存は続きます。選択した履歴とスライダーの時点は共有します。
生データの一時停止は表示だけに作用します。表示は最大1,000行です。
履歴の生データは選択点のUTCに最初に一致するGGAまでを表示するため、
複数日で同じUTCが繰り返されるログには現時点で制限があります。
時系列は有効な測位点が対象であり、測位不能（品質0）は生データで確認します。
左右矢印キーでもタブを切り替えられます。

## 画面の見方

- 「受信中」と測位品質を画面上部に表示します。
- 有効なGGAが3秒以上更新されないと、現在位置のマーカーを非表示にします。
- 測位不可のGGAを受け取った場合も、現在位置としては表示しません。
- その際、過去の軌跡は残し、座標欄には「最後の有効位置」と表示します。
- 品質1は灰色、2は橙色、5は紫色、4は緑色です。
- 無効なGGA、時刻の逆転や重複、2秒を超える測定時刻差で線を分けます。
- 地図では「最新位置を追う」を有効にすると地図が移動します。
- 航空写真とのずれは、GNSSの真値に対する誤差そのものではありません。

「保存した履歴」から計測を選ぶと、その軌跡を表示します。
スライダーで測定点を選び、その点までの軌跡、座標、測位品質、日時を確認できます。
「履歴を再生」は1点につき0.2秒で表示を進めます。
時刻の空白を待つ実時間再生ではありません。
「全軌跡・最後の点」で末尾に戻ります。
日時はRMCとGGAの時刻が一致した場合に日本時間で表示し、日付が取得できなければUTC時刻と「日付不明」を表示します。
ブラウザーの時計やGPS位置は、GNSSの測定値として使用しません。

## 保存先と書き出し

既定では次の場所に保存します。

```text
data/live/
├── history.sqlite3      # 計測一覧と位置データ
├── history.sqlite3-wal  # SQLiteの動作中に作られることがある管理ファイル
├── history.sqlite3-shm  # 同上
└── <計測ID>.log         # 受信した元データ
```

元データは受信するたびにファイルへ書き出し、座標はSQLiteへ逐次保存します。
通常の停止後も履歴を残します。
異常終了した記録は、次の起動時に `interrupted` と表示します。
保存フォルダーをコピーする場合は、先にPythonを終了してください。
停電やOS障害による最後のデータの消失まで保証するものではありません。

画面からCSV、KML、元ログをダウンロードできます。
CSVの `measured` はRMCと対応付けたUTC日時、`received` はPCが解析した時刻です。
ログ再生時の `received` は再生した時刻であり、元の測定時刻ではありません。
KML書き出しは区間ごとの軌跡です。
日時付きピンが必要なら、元ログを従来の変換コマンドで処理します。

```sh
uv run python -m gnss_maps "data/live/<計測ID>.log" --out result
```

保存先と待ち受けポートは変更できます。

```sh
uv run python -m gnss_maps.live --data-dir data/field-test --port 8766
```

サーバーは自分のPCの `127.0.0.1` のみに接続を受け付けます。
スマートフォンなど別機器からのアクセスには対応していません。
`data/` はGitの管理対象外です。
画面は直近50,000点までを表示し、それ以前を含む全データは保存と書き出しで保持します。

## 現時点の検証範囲

- 自動テストで、USB受信の分割行、切断、日付の対応付け、測位不可、古い位置の扱い、保存、HTTP操作を検証。
- Macのブラウザーで架空データによる受信、停止、履歴表示を確認。
- 実機のUSB受信とWindows実機は未検証。
- 地図の利用には、対象範囲のMBTilesを事前に用意する必要があります。

### 経路の途中で地図が途切れる場合

履歴を選び、地図の「全経路の地図を準備（ネット必要）」を押してください。経路全体と周囲の余白を国土地理院から取得し、標準プリセットを置き換えます。対象範囲が配信元に伝わります。範囲が広すぎる場合は取得を中止してエラーを表示します。詳細画像がない場所は、保存済みの粗い画像があれば拡大して補います。どの倍率にも画像がない場所は空欄です。
